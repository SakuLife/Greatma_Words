# 著作権・肖像権ガイドライン

## 重要な注意事項

### 肖像権について

**故人でも肖像権は存続します**（日本では死後50年程度）

ただし、以下の場合は比較的安全です：

1. **歴史的人物・公人**
   - 報道・教育目的での使用は比較的緩い
   - 例：哲学者、政治家、科学者など

2. **パブリックドメインの肖像**
   - 著作権が切れた古い写真・絵画
   - 例：19世紀以前の人物の肖像画

3. **適切な引用**
   - 教育・解説目的での使用
   - 商業利用の場合は要確認

### 著作権について

- **著作権は死後70年**（日本）で切れます
- **思想・哲学の引用**は、適切に引用すれば問題ないことが多い
- **具体的な文章の引用**は、出典を明記し、適切な範囲内で使用

### 推奨される人物カテゴリ

#### ✅ 比較的安全（推奨）

1. **古代・中世の哲学者・思想家**
   - ソクラテス、プラトン、アリストテレス
   - マキャヴェッリ（『君主論』は著作権切れ）
   - カント、ヘーゲル（著作権切れ）

2. **19世紀以前の実業家・政治家**
   - アダム・スミス（経済学者）
   - ベンジャミン・フランクリン
   - リンカーン

3. **著作権切れの現代人**
   - 死後70年経過した人物
   - 例：1954年以前に亡くなった人物

#### ⚠️ 注意が必要

1. **20世紀後半以降の人物**
   - ピーター・ティール（存命）
   - スティーブ・ジョブズ（2011年没、まだ著作権存続）
   - ウォーレン・バフェット（存命）

2. **存命の人物**
   - 肖像権・著作権ともに存続
   - 使用には許可が必要な場合がある

### 安全な使用方法

1. **思想・哲学の解説**
   - 人物の思想を解説する形式
   - 直接的な引用は最小限に

2. **パブリックドメインの画像使用**
   - 古い肖像画や著作権切れの写真
   - またはAI生成画像（人物の特徴を参考に）

3. **出典の明記**
   - 引用元を明記
   - 「〜の著書『〜』より」など

4. **教育目的の明示**
   - 動画説明欄に「教育・解説目的」と明記
